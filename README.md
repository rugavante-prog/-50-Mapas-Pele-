# Pele 40+ — página de vendas

Página estática (HTML + CSS + JS leve), mobile-first, 19 blocos.

## Como editar
- **Links de checkout, parcelas e carrosséis:** `config.js`
- **Textos:** `index.html` (cada bloco tem um comentário com o número dele)
- **Cores e fontes:** topo do `style.css`

## Imagens
Suba as imagens na pasta `img/` com estes nomes (formato .webp). Enquanto a imagem não existir, aparece o espaço vazio tracejado.

| Onde | Arquivo |
|---|---|
| Hero (colagem 2x2) | `hero-1.webp` … `hero-4.webp` (quadradas) |
| Carrossel Entenda sua Pele | `entenda-1.webp` … `entenda-5.webp` (4:5) |
| Carrossel Rotina da Manhã | `manha-1.webp` … `manha-5.webp` |
| Carrossel Rotina da Noite | `noite-1.webp` … `noite-5.webp` |
| Carrossel Ativos Sem Mistério | `ativos-1.webp` … `ativos-5.webp` |
| Carrossel Cada Incômodo | `incomodo-1.webp` … `incomodo-5.webp` |
| Tudo que você vai receber | `receber.webp` (quadrada) |
| Bônus | `bonus-1.webp` … `bonus-4.webp` (quadradas) |
| Planos | `plano-completo.webp`, `plano-basico.webp` (4:3) |
| Compartilhamento (WhatsApp/Facebook) | `og.jpg` (1200x630) |

## Antes de rodar tráfego
- Colar os links de checkout em `config.js`
- Colar o pixel da Meta no `<head>` do `index.html` (tem um comentário marcando o lugar)
- Trocar os 3 depoimentos (bloco 14) por depoimentos reais

GitHub Pages, branch `main`, pasta raiz.
